Configurar o Caddy como proxy reverso

Do container no ar ao HTTPS automático, sem expor a porta da aplicação.

  1. Container com expose, nunca ports

    Assim só o Caddy alcança a aplicação. Com ports, o Docker passa por cima do UFW.

    services:
  app:
    expose:
      - "8080"

  2. Bloco do domínio no Caddyfile

    Uma linha por site. O certificado sai sozinho no primeiro acesso.

    meusite.joaomendes.dev.br {
	reverse_proxy app:8080
}

  3. Validar antes de recarregar

    up -d não relê o Caddyfile. Valide e use reload, que mantém a configuração antiga se a nova tiver erro.

    docker compose exec caddy caddy validate --config /etc/caddy/Caddyfile
docker compose exec caddy caddy reload --config /etc/caddy/Caddyfile

RAG não serve para pergunta que cabe num SELECT

Qual é a diferença entre embedding e RAG? Quando usar SQL em vez de busca por similaridade?

Embedding é o texto virando números que representam o significado. RAG busca os trechos mais parecidos e entrega ao modelo antes de ele responder. Pergunta com resposta exata, como contar registros, continua sendo SELECT.
